# 游戏设计总文档

## 游戏名
parabola——抛物线

## 定位
2D平台肉鸽PVE动作游戏

## 背景
一艘星际飞船在宇宙中航行时意外失控，坠毁在了一颗未知星球上。这里的地表由一层层的浮岛组成，并且遍布神秘诡异的生命体。幸存下来的乘客开始在浮岛间穿梭，借助岛上的物品与各种危险生物进行战斗，并探索星球的历史与现状，以便能找到重返地球的办法。

## 基本玩法
玩家在浮岛（2D平台世界）中左右移动、跳跃和下蹲，拾取场景中散落的物品来对抗随处穿梭的怪物们。每次击败怪物后都会获得随机物品奖励选择，有些浮岛上也有更为强力的增益和减益效果。玩家需要不断通过战斗和抉择来武装强化自己，以迎战最终Boss。

### 操作方式
| 按键 | 行为 |
| :---: | --- |
| A | 向左移动 |
| D | 向右移动 |
| W | 跳跃 |
| S | 下蹲 |
| F | 使用当前物品 |
| R | 与环境交互 |
| 空格 | 让投掷到空中的物品悬停 |
| 鼠标左键 | 拾取物品、选择物品、蓄力投掷物品 |
| 鼠标右键 | 打开物品操作菜单（包含装入背包和丢弃） |

当鼠标指针位于游戏界面边缘时，相机视角会向对应方向滚动，距离边缘越近滚动得越快。

当玩家手中持有投掷型物品时，在游戏画面中（不要太边缘）按下鼠标左键会开始蓄力。以按下时鼠标指针位置与玩家位置的连线为投掷角度（限定在0~90°之间），投掷力度可由鼠标左右拖动来调节，松开鼠标左键会进行投掷动作。蓄力时可以移动但会固定朝向（不随移动方向而改变）并显示预览抛物线轨迹。蓄力时也可以跳跃和下蹲，会改变出手位置。

> 投掷与丢弃的区别：对于投掷型物品来说，投掷出去会生效（例如在一定区域内造成伤害和控制效果），而丢弃是原地掉落，不会触发任何效果。

### 物品分类
1. 投掷型物品：可以蓄力投掷出去的物品，击中敌人造成伤害和控制效果。有些可以停留在空中或地面上持续生效或回收利用。不同物品间可以产生连锁反应。是主要输出手段。每场战斗结束后都会掉落。

> 投掷型物品的伤害和控制效果会根据投掷力度分为三个等级。对于一般物品，投掷力度越大，伤害越高，控制越强。

2. 施放型物品：可以直接在手中施放（有些施放时需要读条引导）生效的物品，给予自身增益效果或对敌人施加减益效果。每场战斗结束后都会掉落。

3. 装备型物品：拾取后自动装备无需主动使用的物品，给予自身增益效果或对敌人施加减益效果。与精英怪战斗结束后会掉落。

### 敌人分类
1. 喽啰：获胜奖励为少量投掷型物品和少量施放型物品。

2. 爪牙：获胜奖励为若干投掷型物品和少量施放型物品。

3. 精英：获胜奖励为大量投掷型物品、若干施放型物品和少量装备型物品。

4. 首领：获胜奖励为大量投掷型物品、大量施放型物品和一个祝福效果。

### 祝福与诅咒
- 祝福：在与首领战斗结束后从3个随机强力增益中选择1个，可能直接改变本局的玩法。

- 诅咒：在随机事件中作为伴随强力奖励出现的负面效果。
